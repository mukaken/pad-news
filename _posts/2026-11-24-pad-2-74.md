Power Automate for desktop の Build 2611（インストーラー版 2.74.191.26302）では、SQL Server への接続と、フローの実行中に問題の原因を調べる操作が改善されました。

## SQL Server の接続を保存前にテスト

「SQL 接続を開く」で接続先の種類に SQL Server を選べるようになりました。接続設定を入力したら、アクションを保存する前に接続をテストできます。データベースにつながるかを先に確認してから、SQL 文の検証に進めます。

## 実行中のログを開発者ツールで確認

詳細ログを有効にすると、開発者ツールの「Logs」で診断情報を含むログをリアルタイムに確認できます。表示は最大1万件で、ログのエクスポートにも対応しています。

## UI 操作ごとにタイムアウトを設定

UI オートメーションのアクションごとに待機時間の上限を指定できます。応答に時間がかかる画面に合わせて、該当するアクションの待機時間を調整できます。
